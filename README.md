# Projekt: django-shop (Moduł 12 – Modele, migracje, admin)

## Uruchomienie projektu
1. Aktywuj środowisko: `venv\Scripts\activate`
2. Wykonaj migracje: `python manage.py makemigrations` i `python manage.py migrate`
3. Utwórz admina: `python manage.py createsuperuser`
4. Uruchom serwer: `python manage.py runserver`
